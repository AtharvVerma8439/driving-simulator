# 2D Python Driving Simulator

A simple, top-down 2D driving simulator built with Python and Pygame. Features smooth acceleration, braking, friction, and realistic steering logic.

## Prerequisites
Make sure you have Python installed, then install Pygame:
\`\`\`bash
pip install pygame
\`\`\`

## How to Play
Run the script from your terminal:
\`\`\`bash
python driving_sim.py
\`\`\`

## Controls
* **W / Up Arrow:** Accelerate
* **S / Down Arrow:** Brake / Reverse
* **A / Left Arrow:** Steer Left
* **D / Right Arrow:** Steer Right
